# homebrew-tap

Homebrew formulae for projects maintained by [@Jacob-Stokes](https://github.com/Jacob-Stokes).

## Available formulae

- [sf-deck](https://github.com/Jacob-Stokes/sf-deck) — a terminal UI for working across Salesforce orgs.

## Install

```sh
brew tap Jacob-Stokes/tap
brew install sf-deck
```

Or, in one line:

```sh
brew install Jacob-Stokes/tap/sf-deck
```

Formulae in this tap are auto-published by each project's release pipeline.
